YOUR INSTALLATION QUEST LOG

Install WhatsApp for WoW.
Keep your evening intact.

WoW Whisper runs alongside World of Warcraft. Download the app, link WhatsApp and return to the game. No Interface/AddOns folder. No WoW restart.

LEVEL REQUIREMENTS

Choose the right build.

Computer Requirements
Mac · Apple Silicon Apple M-series chip, macOS 14 or later
Mac · Intel Intel processor, macOS 14 or later
Windows · x64 Windows 10/11, Microsoft WebView2 Runtime

You also need a WhatsApp account, an internet connection and WoW in windowed or borderless windowed mode. Windows on ARM, Linux, exclusive fullscreen and separate macOS fullscreen Spaces are not supported release targets.

Download from the project's GitHub Releases. Files named “Source code” are for developers; choose a WoW-Whisper-…zip asset to install.

This is early community software. Mac builds are ad-hoc signed, not notarized by Apple; Windows builds are not Authenticode-signed. Review operating-system warnings and the source before deciding to run it.

FOR THE MAC IN YOUR PARTY

Install on macOS.

  1. Open Apple menu → About This Mac. “Chip: Apple …” means Apple Silicon. “Processor: Intel …” means Intel.
  2. Download the matching ZIP below and double-click it to extract it.
  3. Drag WoW Whisper.app into Applications, then open it.
  4. If macOS blocks it, read Apple's guidance for opening apps safely. After attempting to open the app, System Settings → Privacy & Security → Open Anyway may be available. Use this only if you trust the download. Do not disable Gatekeeper globally.
  5. Continue to link your phone. There is intentionally no Dock icon. Use Control+Shift+W to show or hide the panel.

FOR YOUR WINDOWS RIG

Install on Windows.

  1. Download WoW-Whisper-Windows-x64.zip and extract the entire ZIP.
  2. Run wow-chat.exe. Windows may show a security warning because the community build is unsigned.
  3. If the app reports a missing runtime, install Microsoft's Evergreen WebView2 Runtime, then reopen WoW Whisper.
  4. Continue to link your phone. The panel has no taskbar entry; use Ctrl+Shift+W to show or hide it.

PARTY INVITE

Link your WhatsApp account.

  1. Open WhatsApp on your phone and select Settings / menu → Linked devices → Link a device.
  2. Scan the QR code displayed by official WhatsApp Web inside WoW Whisper.
  3. Return to WoW in windowed or borderless mode. Keep the panel visible wherever you want to read incoming messages.
  4. Click the chat to reply. Click back in the game to resume playing.

WhatsApp handles the link, message delivery and its encryption. The session stays in the operating system's WebView profile. You can revoke it at any time in Linked devices on your phone. WhatsApp's linked-device guidance ↗

An incoming message does not intentionally take keyboard focus. Typing a reply requires clicking the chat. Keep private conversations hidden when streaming or sharing your screen.

KEYBINDS, WITHOUT A RAID GUIDE

Make room for your UI.

Control What it does
Ctrl+Shift+W Show or hide. Use Control on Mac, not Command.
Drag the title bar Move the panel.
Bottom-right grip Resize the panel.
A− / A+ Zoom the WhatsApp view.
Pin Toggle always-on-top.

The panel follows WoW and hides when you switch to other apps. Manually hiding it keeps it hidden until you toggle the hotkey. Window size, position and launch options reset when the app restarts.

PICTURES, EMOJI & “WHERE ARE YOU?”

Images and voice notes.

WhatsApp Web supplies profile photos, images, emoji and voice-note controls. The theme preserves the content. Voice recording uses the normal microphone permission prompt.

  • Mac: run the packaged .app so its microphone usage declaration is present. Check System Settings → Privacy & Security → Microphone if needed.
  • Windows: desktop microphone access must be enabled in Windows privacy settings.

Media and recording depend on WhatsApp's WebView support and still need manual validation on each OS. Windows linked-account/game testing remains outstanding. Voice/video calls, camera, screen sharing, external-link opening and attachment downloads are not supported; use the official WhatsApp app or browser for those.

THE NEXT PATCH

Update or uninstall.

To update

Quit WoW Whisper, download the latest release, replace the app or extracted folder and reopen it. There is no in-app auto-updater. This does not require restarting WoW.

To check a download

Each release includes SHA256SUMS.txt. Compare your ZIP's SHA-256 hash with its corresponding line. On Mac use shasum -a 256 filename.zip; in PowerShell use Get-FileHash filename.zip -Algorithm SHA256. A matching checksum confirms file integrity, not software safety.

To uninstall

Quit and delete the app or extracted folder. Unlink it in WhatsApp on your phone to revoke the session. Deleting the executable does not automatically remove the operating system's browser profile.

WHEN THE PULL GOES SIDEWAYS

Troubleshooting.

The window vanished.

Return to WoW and press Ctrl+Shift+W. The panel hides when you switch away or hide it manually. If you pressed ×, launch the app again. There is no Dock or taskbar icon.

The hotkey is already taken.

Close another running copy of WoW Whisper, or choose a different shortcut through the documented launch options, such as --hotkey Ctrl+Alt+W.

It doesn't show above fullscreen WoW.

Use windowed or borderless mode. Exclusive fullscreen and separate macOS fullscreen Spaces are not supported. Keep the pin enabled if you want the panel above the game.

Messages don't appear while it's hidden.

Hidden toast notifications are not implemented. Keep the connected panel visible to watch incoming messages. Sleeping, offline or suspended computers/WebViews cannot be relied on for live delivery.

The QR code, theme or media isn't working.

Try the app's reload control. WhatsApp updates can change embedded-browser support or page structure, and a theme update may be needed. Use official WhatsApp in a supported browser if linking fails. Report the app version and OS; never include a live QR code, private chats or account data.
