A Warcraft-styled WhatsApp desktop companion. Keep WoW in windowed/borderless mode; no game restart or AddOns-folder installation is needed.

| Platform | Asset |
| --- | --- |
| macOS 14+ · Apple Silicon | `WoW-Whisper-macOS-arm64.zip` |
| macOS 14+ · Intel | `WoW-Whisper-macOS-x64.zip` |
| Windows 10/11 · x64 | `WoW-Whisper-Windows-x64.zip` |

Extract the ZIP. On Mac, move **WoW Whisper.app** to Applications. On Windows, run **wow-chat.exe** (requires Microsoft WebView2). Link through WhatsApp on your phone → Linked devices. **Ctrl+Shift+W** toggles the panel; use Control on Mac.

Read the [installation guide](https://github.com/MPJHorner/Wow-Whatsapp-Addon#install) before opening. These community builds are not Apple-notarized or Windows Authenticode-signed. `SHA256SUMS.txt` lists the archive checksums.

This is an early desktop companion release, not a Lua addon or an official Blizzard/WhatsApp product. Original source is MIT; Blizzard assets and other third-party rights are excluded. See the bundled notices. Native builds do not establish that every WhatsApp media flow has been tested on each OS.
